# A Lawyer's Diary — React frontend

React + TypeScript + Vite + Tailwind CSS frontend for the FastAPI backend in
`../backend`. See the root [README](../README.md) for full setup instructions
(this app is step 4 there).

Quick start:

```bash
npm install
cp .env.example .env   # set VITE_API_BASE_URL if the backend isn't on :8000
npm run dev
```
